# VAAD HR Frontend

A modern Human Resource Management (HRM) web application built with React, TypeScript, and Vite. This frontend integrates with the VAAD HR backend to provide employee management, leave management, departments, document management, authentication, and more.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- React Router
- Axios
- TanStack Query
- React Hook Form
- Zod
- Sonner

## Features

- JWT Authentication
- Role-Based Access Control
- Employee Management
- Department Management
- Leave Management
- Document Management
- Responsive Dashboard

## Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Install dependencies

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev
```

### Build for production

```bash
pnpm build
```

## Environment Variables

Create a `.env` file in the project root.

```env
VITE_API_URL=http://localhost:4000/api
```
