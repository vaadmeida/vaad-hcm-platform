# VAAD HR Platform

A modern Human Resource Management System built for VAAD.

## Tech Stack

### Frontend
- React 19
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI
- React Query
- React Hook Form
- Zod
- Zustand

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication

## Features

- Authentication
- Role-based Access Control
- Employee Management
- Department Management
- Leave Management
- Document Management
- Dashboard Analytics
